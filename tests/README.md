# Тесты VK-бота

Автоматические тесты для `vk_bot/exercises/*` — эмулируют переписку
пользователя с ботом без реального VK и без сервера (VK и Django API
подменены заглушками из `conftest.py`).

## Как запустить

Из корня репозитория (`D:\observatory`):

```
pip install pytest vk_api --break-system-packages
python -m pytest tests/ -v
```

(на Windows без `venv`, если стоит обычный Python — `pip install pytest vk_api`
без флага `--break-system-packages`)

## Что проверяется

- редизайн клавиатуры упражнений — 2 кнопки («➡️ Продолжить» / «💾 Сохранить и начать заново»)
- «Продолжить» и «Начать заново» на экране возобновления прогресса
- защита от бага с подстрокой (реальный ответ, случайно содержащий слово
  «заново» или «продолжить», не должен приниматься за команду)
- «Мои роли» — переход между разделами без ограничения на минимум ролей
- «Дневник» — нет литерального `None` при сохранении неполного прогресса
- «Список счастья» — экран 20/20 использует ту же клавиатуру, что и весь сбор
- «Стоп-техника» — счётчик попыток
- «Поиск стресса» — возобновление с середины (фазы analysis/question) не теряет
  и не дублирует данные, результат сохраняется под правильным типом упражнения

Стоит перезапускать этот набор после любых правок в `vk_bot/exercises/` или
`vk_bot/keyboards.py`, перед деплоем на сервер.
